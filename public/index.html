Container Configuration (Dockerfile)

Production Setup

This project uses a Dockerfile to package the Node.js app into a portable, lightweight container.

Dockerfile 
FROM node:18-alpine

# Set working directory
WORKDIR /app

# Copy dependencies config files
COPY package*.json ./

# Install production dependencies
RUN npm ci --only=production

# Copy app code files
COPY . .

# Expose application port
EXPOSE 3000

# Start app server
CMD ["node", "server.js"]
